ChaosFilter – Network & Qdisc Setup Guide
========================================

This project uses Linux traffic control (tc), network namespaces,
veth pairs, and IFB to simulate network delay and packet loss.

You MUST complete this setup ONCE (per reboot) before running the program.

All commands require sudo.


------------------------------------------------------------
1. Create the chaos network namespace
------------------------------------------------------------

sudo ip netns add chaos
sudo ip netns exec chaos ip link set lo up


------------------------------------------------------------
2. Create the main test veth pair (vethA <-> vethB)
------------------------------------------------------------

# Create veth pair
sudo ip link add vethA type veth peer name vethB

# Move vethB into chaos namespace
sudo ip link set vethB netns chaos

# Assign IPs
sudo ip addr add 10.0.0.1/24 dev vethA
sudo ip link set vethA up

sudo ip netns exec chaos ip addr add 10.0.0.2/24 dev vethB
sudo ip netns exec chaos ip link set vethB up

# Force all chaos traffic through vethB
sudo ip netns exec chaos ip route add default via 10.0.0.1


------------------------------------------------------------
3. Create the control (baseline) veth pair
------------------------------------------------------------

# Create control veth pair
sudo ip link add control type veth peer name control-peer

# Move control-peer into chaos namespace
sudo ip link set control-peer netns chaos

# Assign IPs
sudo ip addr add 10.0.1.1/24 dev control
sudo ip link set control up

sudo ip netns exec chaos ip addr add 10.0.1.2/24 dev control-peer
sudo ip netns exec chaos ip link set control-peer up


------------------------------------------------------------
4. (Optional sanity check)
------------------------------------------------------------

You should be able to ping the host from inside chaos:

sudo ip netns exec chaos ping -I vethB 10.0.0.1
sudo ip netns exec chaos ping -I control-peer 10.0.1.1

Both should show very low latency (<1 ms) with 0% packet loss.


------------------------------------------------------------
5. Run ChaosFilter
------------------------------------------------------------

From the project directory:

sudo AYA_BUILD_SKIP=1 cargo run -p aya-qdisc

Use commands like:
  add vethA 100 50
  mod vethA 200 70

The program will automatically:
- attach netem qdiscs
- create IFB inside the chaos namespace
- apply ingress + egress shaping


------------------------------------------------------------
Notes
------------------------------------------------------------

• This setup must be repeated after reboot
• Do NOT manually add netem or IFB qdiscs
• Do NOT modify the "control" interface
• The program manages qdiscs dynamically
