ChaosFilter

A Rust workspace that combines a CLI controller with an eBPF program (via Aya) to inject controlled chaos into Linux systems—starting with network impairment (delay/loss) and resource stress controls.

Project overview

What it does

ChaosFilter is built to inject failure conditions in a controlled, repeatable way. It’s aimed at testing resilience (timeouts, retries, backpressure, fallbacks) under real-ish Linux behavior.

  • Network impairment: delay and packet loss on an interface
  • Config-driven: one TOML file describes a run (“plan”)
  • eBPF under the hood: integrates with the kernel via Aya
How it’s used

The CLI reads a config, validates it, then applies injectors for a scheduled duration. Your README.md documents Linux prerequisites (bpftool, memlock, tc) and includes a sample TOML configuration.

Quick help
cargo build
cargo run -- --help

Environment setup (Linux)

ChaosFilter is documented for Linux (eBPF, bpftool, tc). Your repository notes that Secure Boot can interfere with some eBPF behavior.

System packages
sudo apt update
sudo apt upgrade -y

sudo apt install -y \
  build-essential clang llvm libelf-dev zlib1g-dev libclang-dev \
  linux-headers-$(uname -r) pkg-config bpftool iproute2 iptables \
  net-tools curl
Rust + BPF target
curl https://sh.rustup.rs -sSf | sh
source $HOME/.cargo/env

rustup target add bpfel-unknown-none

If you’re using Aya build scripts, your README recommends installing cargo-generate.

Kernel eBPF features
bpftool feature
cgroup v2
stat -fc %T /sys/fs/cgroup/

You should see cgroup2fs.

memlock
ulimit -l unlimited

Permanent option is documented in the repository README.

Usage

Validate a config
cargo build
cargo run -- validate -c, --config <path-to-toml-file>
Run chaos with a config
cargo build
cargo run -- chaos -c, --config chaosfilter.toml

Tip: run chaosfilter --schema to print a sample config with variable descriptors (per your README).

Example TOML config

From your repository’s README.md:

name = "netem-test"

[targets]
iface = "enp5s0"
cgroup = "77500" # Optional

[schedule]
duration_s = 10

[injectors.network_config]
enabled = true
target_iface = "enp5s0"
delay_ms = 100
loss_percent = 50.0

[injectors.memory_config]
enabled = false
target_pid = 1234
move_pid = true
enable = ["cpu", "memory"]
cpu_max = "20000 100000"
mem_max = "1G"
